# 🧬 Brand Identity: Alicia Elena

Este skill establece el marco conceptual para transformar una página de servicios genérica en una plataforma de autoridad ejecutiva (Fortune 500).

## 🏛️ Arquetipo y Vibe
- **Arquetipo:** El Sabio Empático / Empoderamiento Ejecutivo Premium.
- **Vibe Visual:** Estilo "Editorial Corporativo". Debe evocar la sofisticación de una revista de negocios de alta gama (estilo moodboard "Bloom").
- **Atributos:** Modernidad, calidez, profesionalismo y cercanía.

## 📏 Reglas de Diseño (UX Forensic)
- **Espacios:** Uso intensivo de espacio negativo (breathing room) para proyectar orden y balance.
- **Simetría:** Estructura simétrica para transmitir estabilidad corporativa.
- **Fotografía:** Imágenes luminosas y limpias.

## Cuándo usar este skill
- Al redactar contenido para el sitio web.
- Al definir la estructura de nuevas secciones de la plataforma.
- Al evaluar si el diseño final cumple con la proyección de "Liderazgo Ejecutivo".
